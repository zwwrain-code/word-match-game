# 单词消消看

面向小学生的英语单词配对消除小游戏。点开英文、中文和图片，三张配成一组就能消掉。由创界科技制作。

玩法受到经典叠牌消除的启发，但名称、画风和规则都是原创：每种单词有「英文 / 中文 / 图片」三张牌，底部有 7 个槽位。

## 怎么玩

1. 点击没有被挡住的牌，牌会进到底部槽位。
2. 同一个单词的英文、中文、图片凑齐，这一组就会消除，并朗读英文单词。
3. 点英文牌时也会朗读单词。
4. 槽位一共 7 格，装满又凑不齐一组就失败。
5. 把场上的牌全部消完即过关。
6. 每关有次数有限的「撤销」和「洗牌」：
   - 撤销：收回刚刚点的那张牌（如果刚好消掉了一组，也会一并撤回）。
   - 洗牌：把还在场上的牌重新排列。

共 3 关，都是层层叠放的「牌山」（不是平铺）：入门约 3 层、小挑战约 4 层、大挑战约 5 层并带短堆。被挡住的牌会变暗，只能点露出来的牌。难度比传统高难关卡更温和，还可用撤销和洗牌。

游戏里有两套词库可以选：译林版小学英语三年级，和原来的趣味入门。译林版只是用了教材里常见的单词和中文释义，并不是译林出版社的官方教材。趣味入门仍是动物、水果、颜色等小学常见词，例如 cat/猫、apple/苹果、red/红色。图片牌使用写实照片（assets/word-*.jpg），方便小朋友一眼认出来。

## 怎么打开

这是一个无需后端、无需登录的静态网页，用手机或电脑浏览器都可以玩。

方式一：直接打开文件

```bash
# 用系统浏览器打开
# macOS
open index.html

# 或者直接双击 index.html
```

方式二：本地小服务器（推荐，部分浏览器对语音接口更友好）

```bash
cd word-match-game
python3 -m http.server 8080
```

然后在浏览器访问：http://localhost:8080/

手机和电脑都可以玩。界面按竖屏手机优先设计，电脑上会居中显示成手机比例的舞台。

## 项目结构

```
word-match-game/
  index.html          # 页面入口
  css/style.css       # 样式
  js/words.js         # 词库与配图路径
  assets/             # 单词写实照片 word-{id}.jpg
  js/logic.js         # 纯游戏逻辑（也可在 Node 里测试）
  js/audio.js         # 英文朗读与简单音效
  js/game.js          # 界面与流程
  test/logic-test.js  # 逻辑冒烟测试
  README.md
```

运行测试：

```bash
node test/logic-test.js
```

## 说明

- 英文朗读使用浏览器自带的 Web Speech API（en-US）。若设备不支持或被系统静音，游戏仍可正常游玩，只是没有声音。
- 第一次点击「开始游戏」或点牌时，会尝试解锁语音和音效（部分浏览器要求先有用户手势）。
- 无需安装、无需联网即可游玩（若想加载在线字体，需要网络；没有网络时会回退到系统字体）。
